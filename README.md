## 💻 Основные проекты

### 🔧 ShortsForge (Video Bot)
**Автоматическая нарезка длинных видео в формат Shorts**  
- Алгоритм гибридной сетки для умного деления видео.  
- Автоналожение субтитров с настройкой шрифтов и стилей.  
- Работа с кастомными размерами, подробное логирование.  
- Полностью упакован в **Docker**.  

**Стек:** Python, FastAPI, OpenCV, FFmpeg, Docker.

---

### 💰 FunPay Bot
**Бот для автопродаж и автоответов с админ-панелью**  
- Первая версия — на плоских файлах.  
- Переписан на **асинхронную архитектуру** с использованием **SQL** и **Redis**.  
- Реализована гибкая система ролей и управление товарами.  

**Стек:** Python, aiogram, SQLite/PostgreSQL, Redis, Docker.

---

### 🎥 TikTok Bot
**Автоматическое удержание стриков в TikTok**  
- Авторизация через браузер с помощью **Playwright**.  
- Управление аккаунтами через куки и прокси.  
- Легко расширяется для других задач (лайки, комментарии, подписки).  

**Стек:** Python, Playwright, asyncio.

---

### 🤖 Telegram Боты (Спорт + LLM)
- **Спортивный бот-калькулятор** — расчёт лактата, темпа, VO2 Max.  
- **Боты с интеграцией LLM** — генерация ответов через API (OpenAI, Groq).  

**Стек:** Python, Telebot, aiohttp, OpenAI API.

---

### 📖 Kivy Visual Novel Engine
**Бэкенд 2D-движка визуальной новеллы на 400 строк кода**  
- Написан за **2.5 дня** прямо на смартфоне в **Pydroid 3**.  
- **Data-Driven архитектура** — весь интерфейс и анимация управляются из словаря `STORY`.  
- Поддержка диалогов, выбора, смены сцен.  

**Стек:** Python, Kivy.
